# Changelog

## 0.1.0

- Capture the original secret-provider callback and receiver without executing custom binding metadata or proxy prototype traps.

- Register the explicit SOAP capability with immutable offline catalogs,
  approved operations, provider credentials and owned client lifecycle.
- Preserve native scalar fidelity and verify compatibility at worker startup.
- Record fixed-label observations with actual SDK privacy coverage.

- Define optional SOAP client, profile and native ownership contracts.
- Admit bounded offline contracts before using the actual native WSDL compiler.
- Decode versioned SOAP responses in owned workers with deadlines and cleanup.
- Reject implicit imports, hostile XML and native method name collisions.
- Normalize an upstream MIT metadata declaration without altering runtime code.
- Capture bounded local WSDL/XSD import graphs and compile them through the native
  cache without implicit filesystem or network resolution.
- Add fixed native HTTPS transport, verified CA/mTLS, captured DNS, absolute
  deadlines and physical socket cleanup with real SOAP client conformance tests.
