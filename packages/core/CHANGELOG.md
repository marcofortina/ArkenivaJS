# Changelog

## 0.1.0

- Add type-only shared MFA subject, atomic challenge/limiter, evidence and secret-provider ports.
- Export the shared literal timeout, metering capacity and event-version constants.

- Add typed errors with immutable metadata and safe external serialization.
- Add validated application composition, dependency ordering and bounded lifecycle cleanup.
- Add immutable configuration generations with protected dynamic reloads.
- Audit committed reloads with a safe fallback for failed diagnostic sinks.
- Preserve long operation deadlines without native timer overflow.
- Compose resource-free facades before startup and activate listeners after resource initialization.
- Capture optional scoped health hooks and order collectors after initialized owners without exposing foreign private components.

- Add the external server TLS file-reference contract and sanitized TLS configuration/material errors.
