# Third-party notices

The optional Kafka adapter uses Confluent Kafka JavaScript 1.11.0 and its bundled librdkafka 2.16.0. The reviewed compatibility diff bounds native build jobs, accommodates pnpm archive paths, retains exact decimal offsets alongside the legacy native numeric fields, preserves nullable/repeated header values and bounds the configured consumer fetch cache. Source compilation is required so these native corrections are actually present. Native platform support remains under verification.
