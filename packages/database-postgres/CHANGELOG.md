# Changelog

## 0.1.0

- Add an owned readonly readiness hook for optional health collectors without relaxing public facade lifecycle guards.

- Use the shared 15-second SQL default and five-second native pool deadline.

- Add root-configured PostgreSQL pools, verified TLS, exact portable binds and
  bounded native cursors with honest nullable counts.
- Add pinned transactions, cancellation, safe error classification and isolated
  optional diagnostic ports without automatic SQL replay.
