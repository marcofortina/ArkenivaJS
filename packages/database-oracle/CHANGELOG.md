# Changelog

## 0.1.0

- Add an owned readonly readiness hook for optional health collectors without relaxing public facade lifecycle guards.

- Add independent native Oracle pools with default Thin and explicit process-wide Thick mode.
- Preserve named binds and NUMBER text, bound cursor fetching, and explicit native LOB ownership.
- Add cancellation, pinned transactions, unknown commit outcomes and safe measurement ports.
- Add mandatory mock contracts and offline empty-pool checks; live compatibility is not verified.
