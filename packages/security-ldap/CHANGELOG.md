# Changelog

## 0.1.0

- Verify native OpenLDAP identity/group ambiguity, attribute size/count limits,
  missing search bases, DNS certificate checks and recovery after rejected data;
  cover deployment, readiness and diagnostic failure boundaries.
- Capture external secret methods without executing callable metadata; reject
  proxies and classification hidden beyond the bounded prototype traversal.
- Add verified native LDAP/LDAPS and mandatory STARTTLS with external secrets, bound filters, approved attribute projections and isolated identity binds.
- Add finite process/socket ownership, paged iteration, nested group limits, safe diagnostics and real OpenLDAP functional tests.
