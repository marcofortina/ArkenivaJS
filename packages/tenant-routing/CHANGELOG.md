# Changelog

## 0.1.0

- Enforce real HTTP, root-owned file and PostgreSQL registry integrations in the existing main-only CI matrices with owned disposable filesystem cleanup.
- Provide the installed offline registry validator with bounded private-file checks, strict deployment options and sanitized exit codes.
- Add opt-in schema-validated supplementary routing event batches with fixed queue bounds, physical exporter ownership, explicit quality/drop reporting and a separate public schema module.
- Correlate verified tenant HTTP and logical usage sessions, retain physical accounting after timeout, and observe distinct upstream quantities without changing metering event v1.
- Add bounded routing metrics and private selected-operation traces through the existing telemetry provider, with single-invocation isolation from diagnostic failures.
- Dispatch approved fixed HTTP implementations through the shared proxy transport with separate transforms, bounded JSON, destination checks and audience/scope/expiry-bound service credentials.
- Compile local tenant dispatch and authorized capability discovery with physical concurrency ownership, strict JSON boundaries and startup SQL dependency ordering.
- Add consistent startup SQL registry reads through injected named pools and an explicit identifier allowlist.
- Add a bounded private file registry provider with production ownership checks, offline validation and optional durable activation admission.
- Validate bounded registry syntax, offline schemas and RFC 8785 content checksums before publishing immutable snapshots.
- Add readonly routing, registry, transformation, credential and capability contracts with explicit activation generations and response limits.
- Export version/default literals and an administrative capability identity without loading HTTP or database engines.
